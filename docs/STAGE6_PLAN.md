# 阶段 6 实施计划

目标版本沿用 Minecraft 26.1.2 / NeoForge 26.1.2.122 / Java 25。
原版基准：本地 `../.references/bloodmagic-original/WayofTime-BloodMagic-35f0188`。

1. 炼金阵服务端、配方与奥术灰烬；先编译，再做渲染。补齐六种基础印记配方。
2. 补齐原版生存依赖：炼金台的奥术灰烬与五种试剂配方，绑定血球支付 LP。
3. 地狱熔炉、恶魔意志组件与宝石、基础意志获取和合成；保留原版单方块结构。
4. 仪式占卜棒、主仪式石、元素符文及 2–3 个基础仪式，验证结构、激活、扣费和停止。
5. 独立服务端断言、真实数据包重载、存档重启、完整 build、资源核查及 API 报告。

源码事实：原版炼金阵是两槽、200 tick 的一次性阵，标准配方不直接扣 LP；
绘制材料为 20 次耐久的奥术灰烬。1.20.1 已将灰烬与试剂制作移到炼金台，
不能直接启用 TartaricForgeRecipeProvider 中注释掉的旧配方。完整链的 LP 来自炼金台和祭坛。
额外为阵配方提供可选 `lpCost`（默认 0），用于数据包扩展及明确的 LP 断言。
Ritual Diviner 为工具，Master Ritual Stone 才是仪式的核心方块。

不生成假多方块要求；结构检查用于阵的支撑、已有祭坛和仪式符文。
高级恶魔意志环境网络、可编辑仪式作用范围和全部高级仪式不在基础迁移范围。

执行结果：五步均已完成当前基础范围；正式 build 与两次独立服务端验收通过，最终 480 项断言。
另补原版祭坛和空白符文入口配方以接通生存链。实现、API 变化、验收日志与剩余范围见 `STAGE6_REPORT.md`。
