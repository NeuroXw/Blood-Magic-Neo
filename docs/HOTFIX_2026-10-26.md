# 1.0.0-beta.1: altar resources and player interactions

## Fixed

- Empty-hand right-clicks on the blood altar, both halves of the alchemy table,
  and the hellfire forge now reach their menu handlers. In Minecraft 26.1.2,
  `PASS` does not invoke `useWithoutItem`; the dispatcher requires
  `TRY_WITH_EMPTY_HAND`. The alchemy array's empty-hand retrieval has the same fix.
- New orbs bind on explicit player insertion into the altar or table catalyst slot,
  including cursor, number-key and shift-click paths. Existing owners are retained.
  Insertion does not sacrifice health. Automated insertion and synchronization do
  not assign ownership. Altar charging transfers LP to the bound soul network.
- Placed and inventory altars reference the upstream `bloodaltar.json` model.
  The upstream altar is a JSON wrapper around `blockaltar.obj`, not a cube built
  with JSON elements. The OBJ geometry and original PNG are byte-identical to
  commit `35f0188665e648d981095b6933cc75b0ca96eca5`.
  The loader is `neoforge:obj`, its MTL references `#default`, and the original
  PNG lives at `textures/block/altar.png` for atlas discovery.

## Validation

The real dedicated-server regression suite includes 504 assertions, covering
right-click packet dispatch, one screen-open packet per click, all four table
orientations and both halves, blood sacrifice, direct/GUI/shift orb insertion,
owner preservation, LP conservation, machine recipes, reloads and saved state.
The resource audit checks all 384 JSON files, 114 item definitions and 33
blockstates, validates model/texture links, and locks altar mesh/texture hashes
to the upstream originals. Release auditing checks every production byte and
excludes test classes from the JAR.

The user stopped desktop control with Escape during this repair. No graphical
client acceptance is claimed for this build. Remaining manual checks are the
rendered altar appearance and real GUI mouse interaction after replacing the
old mod and restarting Minecraft.

## Upgrade

Exit Minecraft, replace the old BloodMagicNeo JAR with
`BloodMagicNeo-1.0.0-beta.1.jar`, then restart. Install only one BloodMagicNeo
version. Existing worlds and item identifiers are retained. If an old unbound
orb is already inside a machine, take it out and insert it again to bind it.

The altar needs its own LP supply: sneak-right-click with an empty hand to
sacrifice health, then insert the orb. Orb charge is stored in its owner's soul
network and can be read with the Divination Sigil. The alchemy table spends
network LP; the hellfire forge needs Demon Will in its catalyst slot.
