# Blood Magic: Neo
**Unofficial NeoForge port of Blood Magic 1.20.1 for Minecraft 26.1.2.**

This is an early Alpha community port. The goal is to bring the core mechanics of Blood Magic into the new 26.1.2 environment using NeoForge. 

**Please read the Known Issues before playing. Backup your worlds!**

## Current Features
- **Blood Altar:** Tiers 1-5, rune detection, LP crafting, and a basic GUI.
- **Blood Orbs:** All 5 tiers, player binding, and cross-dimensional soul network.
- **Sigils:** 6 basic sigils and the survival crafting chain.
- **Hellfire Forge:** Demon Will storage and crystal crafting.
- **Rituals:** Ritual Diviner + 3 basic rituals.

## Known Issues
- **Visuals are incomplete:** The Altar and some machines currently use placeholder models. Some textures might show up as purple/black squares (missing textures).
- **Missing Items:** The Sacrificial Knife and Altar Hopper are not implemented yet.
- **GUI:** The interface coordinates might be slightly misaligned.
- **Please backup your world** before loading this mod.
