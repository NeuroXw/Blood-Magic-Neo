# Blood Magic: Neo

Blood Magic 1.20.1 的非官方 NeoForge 移植版，适用于 Minecraft 26.1.2。

这是一个 Beta 社区移植项目。项目目标是将 Blood Magic 的核心机制迁移到基于 NeoForge 的 Minecraft 26.1.2 环境中。

## 当前功能

- **血腥祭坛：** 支持 1 至 5 级、符文检测、LP 合成和自定义 GUI。
- **血球：** 支持全部 5 个等级、玩家绑定和跨维度灵魂网络。
- **仪式：** 已注册 32 个仪式，其中 27 个具有实际效果，包括满泉仪式、绿林仪式和羽毛刀仪式。
- **恶魔意志系统：** 包含 5 类意志、区块光环、晶簇、宝石、催化剂、仪式配置和 HUD 计量条。
- **印记：** 包含 14 个实用印记（生长、采掘、磁化等）。
- **机器：** 炼金台、地狱熔炉、炼金反应室、恶魔坩埚、恶魔结晶器和恶魔水晶塔。
- **地牢方块：** 已实装 135 个地牢装饰方块。
- **工具与物品：** 牺牲匕首、炼金瓶、激活水晶、仪式占卜棒和仪式调整器。

## 问题反馈

如果遇到崩溃、GUI 显示异常、机器无法工作等问题，请在 **Issues** 页面提交 Issue，并附上 `latest.log` 以及复现问题的步骤。
